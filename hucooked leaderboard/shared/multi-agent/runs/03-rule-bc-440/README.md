# 440 周期规则策略 · BC

每局平均出餐 **22.00** 单，团队得分 **440.00**，同步成功率 **100.00%**，等待 **11.00** 步。

Shared 三人连续订单，环境版本 `de37e0818c2e76311e105ab8689e5162bd84133f`，固定厨房，24 个配对种子 84031–84054，每局 300 步。同步成功率按各局成功出锅次数除以尝试步数后取平均。

## 模型与训练设置

- 周期规则老师提供 49 步的开局及 26 步循环。CPU，种子 488。Manager 190→128→128→9（42,121），Worker 199→128→128→6（42,886），Critic 190→128→128→1（41,089）。隐藏层 Tanh，执行参数 85,007，检查点共 126,096。策略可观察周期相位。
- 示范 1 局、300 环境步，3 人共 900 条子目标标签和 900 条动作标签。两个网络分别使用全批交叉熵和 Adam 0.003，Manager 拟合 291 次，Worker 拟合 293 次。入榜采用 BC 权重，PPO 环境步为 0。
- 教师评估结束时刻为 5.36 秒，采集示范及两个网络拟合结束为 8.05 秒，阶段差 2.69 秒。含评估的首次模仿结果记录于 17.01 秒。整个作业含后续 12 轮 PPO、27,648 步及评估为 83.93 秒；以上时间均从训练脚本启动计，不含前期老师搜索。
- 本版老师保存在 `evidence/plan.json`。训练入口为 leaderboard 下的 `shared/train_schedule.py`。
