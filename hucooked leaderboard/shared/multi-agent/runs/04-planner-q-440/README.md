## 模型与训练设置

- 420 BC 仅用于提供经验；最终执行网络为集中式联合动作 Q：121→128→128→216，ReLU，59,992 个参数。测试在全部 216 个联合动作上取最大值。训练设备 RTX 3090，种子 488。
- 420 策略和三个规划候选各提供 90 步前缀（4 段共 360 步，无完整训练回合）；再执行 2,570 次单步扰动，保留 101 条局部分支。合计 2,930 次环境步调用，整理出 169 个状态、274 条不同转移。单独筛选规划候选时另有完整局，其逐项得分见 `evidence/proposals/results.jsonl`，未混入前述 Q 学习步数。
- 数据上做 300 个剩余时域的价值递推，折扣 0.995，出餐奖励除以 20。AdamW 学习率 0.001、权重衰减 0.00001、batch 1,024。入榜的宽度 128 网络做了 1,200 次梯度更新（1,228,800 条状态及时域抽样，重复使用离线数据），无 PPO 环境步。
- 脚本启动后 1.74 秒完成采集与目标构造，8.21 秒时第 1,200 次更新验证为 440；21.12 秒时完成该宽度的开放动作 24 局评估。这些时间不含先前 420 基线训练和候选搜索，历史记录没有单独计量候选搜索耗时。
- 训练入口为 leaderboard 下的 `shared/prep_neural_q.py`，其 checkpoint 参数取第二版的 `train/best.pt`，proposals 参数取本版的 `evidence/proposals/`。
