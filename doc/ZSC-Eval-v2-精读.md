# ZSC-Eval 论文精读

阅读范围为 arXiv v2 正文、附录 A–D，以及官方实现和两份公开 HSP 第二阶段 actor 权重。[论文](https://arxiv.org/html/2310.05208v2) · [官方实现](https://github.com/sjtu-marl/ZSC-Eval/tree/f940869afc42b688332a385892d8dbb57a190f95)

## 从固定搭档的高分到陌生搭档的评测

零样本协作要求智能体直接和训练中没见过的搭档合作。Overcooked 自博弈可能学出稳定分工，例如一人煮汤、一人取盘上菜。换一个也喜欢煮汤的队友，两人就可能挤在锅边。论文要解决的是如何可靠地测出这类泛化差异。测试队友若由相似训练机制产生，换 seed 也可能只是在重复测类似分工。直接平均原始分数还会把队友本身的任务能力混入评估。图 1 分别处理候选生成、应对方式覆盖与得分校准。

## 生成、筛选与评分

### 给一个玩家行为偏好

对一名玩家用 $r_w(s,a)=r(s,a)+\phi(s,a)^\top w$，其余玩家用原任务奖励。$s$ 是状态，$a$ 是联合动作，$r$ 是标量任务回报，$\phi,w\in\mathbb R^m$ 分别是事件特征与权重。假设两维是取盘与取汤，$w=(10,-20)$，原奖励为 0。只取盘时得到 10，只取汤时得到 −20，原奖励玩家这两步仍是 0。用 PPO 联合训练得到偏好策略及一个针对它的近似最佳响应。原任务奖励保留，权重大小和非零项个数受限，无法与响应完成交付的候选会被过滤。附录 C.3 报告最多 194 个候选，选至多 30 个。事件奖励已有 HSP 前例，本文用受约束的偏好空间构造评测候选。

### 按响应的多样性选队友

两个队友走位不同，但都把汤放在同一个台面让你上菜，这两次测试可能都在考同一种配合。设 $\theta_i\in\mathbb R^m$ 是候选 $i$ 的近似最佳响应的平均回合事件计数。对含 $M$ 个候选的子集构造 $M\times M$ Gram 矩阵 $K_{ij}=\theta_i^\top\theta_j$，以 $\det K$ 衡量 BR-Div。若两个响应是 $(2,0)$ 和 $(1,0)$，则行列式为 $4\times1-2^2=0$。若第二个响应是 $(0,1)$，行列式为 $4\times1-0^2=4$。这个量同时受方向和向量长度影响。作者用 DPP 反复抽样、从抽到的组合中选高分子集，并用较早的 checkpoint 增补技能水平差异。

图 2 用同一候选池比较 P-Div 和 BR-Div。在同一子集大小下，BR-Div 在它直接优化的响应多样性上更高。附录 D.2 的事件热图补充了行为证据，例如部分选出的响应更频繁使用中转台。真人实验没有只替换筛选步骤，因此无法把排序一致性单独归因于 BR-Div。

### 用每个搭档的近似最佳响应校准

对固定队友或队友组合 $L$，比较被测策略 $\pi$ 的团队回报与针对 $L$ 的近似最佳响应的团队回报。

$$
q_L=\frac{J(\pi,L)}{J(\widehat{\mathrm{BR}}(L),L)}.
$$

和 A 得 60 分、响应得 100 分，比值 0.60。和 B 得 40 分、响应得 50 分，比值 0.80。原始回报更高的是 A，相对参照发挥更充分的是 B。若四个条件的比值是 0.20、0.60、0.80、1.00，四分位均值（IQM）为 $(0.60+0.80)/2=0.70$。分母是经验参照，若被测策略超过该参照，比值可以大于 1。IQM 对两端条件不敏感，因此作者还报告区间和分布。论文最有辨识度的设计是用最佳响应同时决定考什么、以及每道题以什么水平作为参照。

## 实验支持到哪里

- 表 2 比较五种方法的真人搭档排序。Coordination Ring 的 Spearman 相关为 0.90，与人类代理并列。Counter Circuit 为 1.00，人类代理为 0.60。附录 C.4 有 145 份有效参与数据。结果支持两个布局中的算法排序，无法据此判断候选池是否代表真实部署人群。
- Forced Coordination、Asymmetric Advantages 在报告设置下较难拉开算法差距。共享台面调度、双向传递和多食谱增加了任务所需的协作方式。专家搭档上的 BR-Prox 更低，说明相对其参照的缺口更大。绝对回报需另查。
- GRF 表 3 中 SP 为 0.20（95% CI 0.14–0.24），TrajeDi 为 0.81（0.75–0.89），HSP 为 0.80（0.72–0.88）。后两者区间重叠。附录 B.2 描述三人进攻队，正文 §5.1 有一句写成 ego 与另外三人协作，两处口径不一致。附录 C 也列出方法间不同的训练步数与实现调整。

## 网络结构与参数量

ZSC-Eval 是评测工具，流程本身无固定网络。附录 C 描述 PPO 与 centralized critic，但未列逐层结构与参数表。以下是从两个作者公开 checkpoint 读出的 HSP 第二阶段 ego actor。训练用 critic 独立处理共享观测并输出价值，所查权重只包含 actor。

| 网络阶段 | Overcooked random1，HSP s12 | GRF，HSP s9 |
| --- | --- | --- |
| 输入 | 5×5×20 网格特征 | 58 维向量 |
| 编码器 | 三层 3×3 CNN，20→32→64→32，展平后 800→64→64→64 | 输入 LayerNorm，MLP 58→64→64→64 |
| 时间建模 | 单层 GRU(64)，LayerNorm | 单层 GRU(64)，LayerNorm |
| 输出 | 64→6 动作 logits | 两层宽度 64 的 MLP，64→19 动作 logits |
| checkpoint 参数元素 | **128,198** | **56,071** |
| 前向使用 | **128,198** | **47,495** |

Overcooked 的卷积 42,752，三层全连接与 LayerNorm 59,968，GRU 与 LayerNorm 25,088，动作头 390。第一层卷积为 $32(20\times3\times3+1)=5,792$。GRU 有两组 $192\times64$ 权重和两组 192 维偏置，LayerNorm 另有 128 个参数。
